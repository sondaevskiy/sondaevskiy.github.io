Privacy Policy

Last updated: 26 October 2026

Reels Publisher is a personal tool used only by its owner to publish videos to the owner's own accounts on Instagram, TikTok and YouTube.

What data is accessed

When an account is connected, the tool receives an access token from the platform (Google/YouTube, Meta/Instagram or TikTok) and, for YouTube, the name of the connected channel. With these permissions the tool only uploads videos chosen by the owner and reads basic account information to confirm which account is connected.

How data is stored and used

Tokens are stored only on the owner's computer and the owner's private server. They are used solely to upload the owner's videos. No data is sold, shared with third parties, used for advertising or used to train any model.

Google user data

Reels Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Deleting data

Disconnecting an account in the platform's settings revokes the token immediately; the owner then deletes the stored token.

Политика конфиденциальности

Reels Publisher — личный инструмент, которым пользуется только его владелец, чтобы публиковать видео в собственные аккаунты в Instagram, TikTok и YouTube. Инструмент получает от площадки токен доступа и, для YouTube, название канала. Токены хранятся только на компьютере и личном сервере владельца и используются только для загрузки его видео. Данные не продаются, не передаются третьим лицам и не используются для рекламы. Доступ можно отозвать в любой момент в настройках аккаунта площадки.
